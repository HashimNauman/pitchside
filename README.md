# Pitchside

A self-contained 2v2 football league tracker — log matches, auto-build the standings, and share the table.

**Live app:** open `index.html` (or the GitHub Pages link once published).

## Features
- Standings with podium, points, goal difference, and a last-5 form guide
- Log 2v2 matches with optional goal scorers
- Stats: records, top scorers, best partnerships, and head-to-head
- Season archive + reset, and JSON backup export/import
- One-tap shareable league-table image
- Light & dark themes

## Notes
- All data is stored locally in your browser (`localStorage`) — it stays on the device you use, and is not synced between devices.
- Everything runs from a single HTML file; the only external dependency is the Saira web font (falls back to a system font offline).
